# OceanX Education Programme Builder

A single-page tool for Partnerships to shape an OceanX Education programme live with a potential partner.

- **Builder:** set the length, audience, number of learners and partner organisation; pick one or more science themes (3 or more makes it a hackathon) and the modules learners will work through.
- **Overview:** a sponsor-ready summary: the learning journey in phases, the Ocean Literacy Principles, why it matters now, where it leads, and common questions. Save as PDF prints two A4 landscape pages.

Open `index.html` in a browser. No build step or server needed.

Content (themes, modules, wording) lives in the data section at the top of the script in `index.html`.
